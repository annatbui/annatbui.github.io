# annatbui.github.io

Personal website of Anna T. Bui, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

- Sidebar details and links: `author` section of `_config.yml`
- Home page: `_pages/about.md`
- Research pages: `_portfolio/`
- CV: `files/cv-2024.pdf`
- Top menu: `_data/navigation.yml`

Pushing to `main` builds the site and publishes it to the `gh-pages` branch (`.github/workflows/deploy.yml`).
